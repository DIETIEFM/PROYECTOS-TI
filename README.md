# PROYECTOS-TI

Proyectos del área de TI de **Excellence Freights**.

- [`erp/`](erp/README.md): sitio web del ERP, con el menú principal de las áreas Operaciones, Torre de Control, Finanzas, Mantenimiento, Almacén de Refacciones, Control de Combustible, Compras, Recursos Humanos, Gestoría, Servicio Médico, Monitoreo, Servicio al Cliente, Gerencial y TI (con Mesa de ayuda).
- [`identidad-corporativa/`](identidad-corporativa/README.md): colores, tipografías, logos y tokens (CSS, JSON y Tailwind) de la imagen corporativa, para usarlos en todos los desarrollos.
- [`DESPLIEGUE-IIS.md`](DESPLIEGUE-IIS.md): cómo publicar el ERP en el servidor IIS de Azure.
