Usuarios y accesos

Usuarios que pueden entrar al ERP y el área a la que tiene acceso cada uno. Los usuarios de TI son administradores y ven todas las áreas. La Mesa de ayuda está disponible para todos.

Cómo agregar o quitar usuarios

  1. Edita el Excel de control de acceso (columnas Modulo, Usuario, Password).
  2. Ejecuta python3 herramientas/generar_usuarios.py ruta/usuarios.xlsx desde la carpeta del proyecto.
  3. Se actualiza erp/assets/js/usuarios.js con las contraseñas cifradas. El Excel no se sube al repositorio.

Versión de prueba: el estado de las contraseñas que ves aquí y el botón "Restablecer" aplican solo a este navegador, porque todavía no hay un servidor central.
